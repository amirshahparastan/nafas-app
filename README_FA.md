# نفس — Nafas Pro v0.7.0

نسخه ۰.۷ تمرکز ویژه روی **Polish بصری، ورودی مالی حرفه‌ای و آمادگی لانچ** دارد.

## مهم‌ترین تغییرات
- ورودی مبلغ اختصاصی با واحد «تومان» به‌صورت Badge جدا، بدون مخفف «م»
- فرمت سه‌رقمی مبلغ و گزینه‌های سریع «۵/۱۰/۲۰/۵۰ میلیون»
- حذف نمایش `۱.۸م` از صفحه شروع و جایگزینی با عبارت خوانای «۱٫۸ میلیون تومان»
- پالت ثانویه کنترل‌شده برای گرما و روح: آفتابی، آبی، یاسی و رز؛ سبز همچنان هویت اصلی نفس است
- رنگ‌گذاری معنایی ابزارهای داشبورد، هدف مالی، دیوار امید و سلامت
- Vazirmatn، RTL، جلالی و Persistence نسخه وب حفظ شده‌اند
- Notification Web fix نسخه ۰.۶.۱ داخل این نسخه نیز وجود دارد

## اصل طراحی رنگ
رنگ‌های جدید نقش معنایی دارند و تزئینیِ بی‌قاعده نیستند:
- سبز: مسیر و موفقیت
- نارنجی/مرجانی: اقدام فوری مثل «الان هوس کردم»
- طلایی/آفتابی: پول و دستاورد
- آبی: تقویم، تحلیل و بینش
- یاسی: جامعه و تجربه شخصی
- رز: کمک و ایمنی

```bash
flutter clean

```

## وضعیت لانچ
ورود واقعی OTP/Google، Sync ابری و Notification زمان‌بندی‌شده Android همچنان به Backend/Android SDK متصل نشده‌اند و در UI جعلی نشده‌اند. قراردادهای فنی و Release Blockerها در `docs/` مشخص شده‌اند.
