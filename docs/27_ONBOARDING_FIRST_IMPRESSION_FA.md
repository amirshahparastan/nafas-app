# Onboarding / First Impression — v0.6

هدف صفحه اول این است که کاربر در کمتر از ۱۰ ثانیه بفهمد «نفس» چه کاری انجام می‌دهد و چرا با یک شمارنده ساده ترک سیگار فرق دارد.

## پیام اصلی
- ترک را قابل‌دیدن کن.
- هوس را مدیریت کن.
- پول سیگار را به هدف واقعی تبدیل کن.
- از تجربه آدم‌های دیگر امید بگیر.

## ساختار صفحه اول
1. برند + نشانه حریم خصوصی.
2. Hero واضح با سه خروجی ملموس: روز پاکی، نخ نکشیده، مبلغ ذخیره.
3. سه ارزش اصلی محصول: مدیریت هوس، هدف مالی، دیوار امید.
4. توضیح زمان تنظیم اولیه (کمتر از ۲ دقیقه).
5. CTA اصلی: «شروع مسیر من».
6. CTA ثانویه سفید: «قبلاً حساب داشتم / بازیابی اطلاعات».
7. نشانه Persian-first: فارسی، جلالی، ذخیره خودکار.

## قانون UX
ورود/ساخت حساب نباید جلوی شروع ترک را بگیرد. کاربر می‌تواند مهمان شروع کند و بعداً برای بکاپ و Sync حساب متصل کند.
