# Craving Personalization

## Flow
شدت → محرک → انتخاب راهکار → Session کوتاه → شدت بعد → ثبت نتیجه

## محرک‌ها
Presetها فقط برای سرعت هستند. کاربر باید همیشه بتواند متن آزاد وارد کند.
نمونه Preset: استرس، بعد غذا، قهوه، جمع دوستان، بی‌حوصلگی، عادت.

## راهکارها
Preset: تنفس آرام، آب، قدم زدن، تغییر فضا.
کاربر می‌تواند «راهکار شخصی» بسازد.

## یادگیری محصول
هر CravingLog شامل Trigger + Intervention + Passed است. با داده کافی می‌توان راهکارهایی که برای همان کاربر بیشتر جواب داده‌اند بالاتر نمایش داد.

## دلیل شخصی ترک
در Setup ثبت می‌شود و فقط در لحظات مناسب مثل Craving نشان داده می‌شود، نه به شکل پیام آزاردهنده.
