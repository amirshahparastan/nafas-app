# Nafas v1 RC2 — رفع موارد تست نصب

- حذف پس‌زمینه سفید آیکن و تولید PNG دارای Alpha.
- Adaptive launcher icon برای Android 8+ با پس‌زمینه برند.
- اضافه‌شدن فعال‌سازی اعلان از داخل اپ و مسیر مستقیم به تنظیمات اعلان Android.
- تازه‌سازی وضعیت مجوز پس از بازگشت از تنظیمات گوشی.
- جایگزینی انتخابگر ساعت انگلیسی با انتخابگر ۲۴ساعته فارسی و ارقام فارسی.
- اضافه‌شدن Flutter localizations برای `fa_IR`.
- عملیاتی‌شدن تماس با فرد مورد اعتماد و اورژانس از طریق شماره‌گیر گوشی.
- حذف ادعاهای اشتباه Onboarding درباره بکاپ ابری فعال.
- پاک‌سازی چند عبارت انگلیسی UI (`Timeline`, `Badge`, `Push`, `Android Release`).
- Build number: `1.0.0+11`.
