# PRD V1 — نفس

## هدف V1
کاربر در کمتر از ۲ دقیقه setup شود، ارزش مالی ترک را ببیند، در کمتر از ۲ لمس به مدیریت هوس برسد و بتواند از تجربه موفق دیگران امید بگیرد.

## Must Have
- Onboarding + Consumption Setup
- Quit Date
- Financial Goal
- Dashboard پویا
- Craving: intensity → trigger → intervention → result
- Health timeline
- Goal tracking
- Stats پایه
- Slip logging با حفظ Journey
- Achievements
- Settings
- Local persistence
- Local notifications opt-in
- Privacy Policy + Health Disclaimer
- **Hope Wall**: feed، پست کوتاه، alias، verified progress badge، reaction، report
- Backend moderation برای Hope Wall

## Non-goals V1
- کامنت عمومی
- دایرکت/چت
- تعداد follower
- تشخیص پزشکی یا AI درمانی
- حساب کاربری اجباری برای core offline
- تبلیغات داخل Craving Flow

## Success Metrics
- Setup completion > 70%
- Day-1 return > 35%
- Craving completion rate
- Goal creation rate
- Slip return rate
- درصد کاربران فعال دیوار امید
- Hope reaction per post
- Report rate و moderation turnaround

## Acceptance
هر Feature باید stateهای empty/loading/error/success، RTL کامل، tap target مناسب و تست روی حداقل 320 و 440 پیکسل عرض داشته باشد.
