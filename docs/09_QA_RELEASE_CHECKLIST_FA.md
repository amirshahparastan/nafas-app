# QA & Release Checklist

## Functional
- onboarding کامل
- محاسبات پول/نخ/روز
- craving before/after intensity
- slip logging
- goal empty/complete
- Hope Wall compose/reaction/report
- Community empty/error/loading
- reset confirmation

## UI
- عرض 320/360/390/440
- textScale 1.0 و 1.3
- Back arrow سمت راست در تمام صفحات
- Secondary button سفید
- keyboard overlap
- dark craving contrast
- tap targets >= 44px
- no overflow با متن بلند فارسی

## Community Safety

- توهین
- محتوای خودآزاری/خطرناک طبق policy
- توصیه پزشکی نامعتبر
- duplicate reports
- rate limit

## Release
- versionName/versionCode
- release signing
- AAB/APK تست‌شده
- privacy URL
- moderation contact
- screenshots واقعی
- changelog
