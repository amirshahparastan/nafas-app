# Help & Safety

این بخش جایگزین اورژانس یا مراقبت پزشکی نیست.

## سه سطح کمک
1. **فرد مورد اعتماد**: کاربر خودش نام و شماره را انتخاب می‌کند.
2. **کمک تخصصی**: هدایت غیرتشخیصی به پزشک/متخصص ترک دخانیات.
3. **اورژانس**: برای علائم شدید مانند درد شدید قفسه سینه، تنگی نفس جدی یا غش، اپ نباید تمرین تنفسی را جایگزین کمک پزشکی کند.

## حریم خصوصی
- شماره فرد مورد اعتماد در Feed یا Community نمایش داده نمی‌شود.
- در Backend آینده باید encrypted-at-rest و حداقل‌سازی داده رعایت شود.
- تماس/باز کردن شماره باید فقط با اقدام صریح کاربر انجام شود.

## وضعیت v0.4
برای حفظ build آفلاین و بدون dependency خارجی، شماره‌ها کپی می‌شوند. در Android Release تماس مستقیم با یک action صریح و قابل بازگشت اضافه می‌شود.
