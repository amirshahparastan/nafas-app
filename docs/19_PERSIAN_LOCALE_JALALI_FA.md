# استاندارد فارسی‌سازی و تقویم جلالی — Nafas v0.4

## تصمیم معماری
- UI و تجربه کاربر: `fa_IR`، راست‌به‌چپ و Persian-first.
- فونت رسمی کل محصول: **Vazirmatn** و به‌صورت Asset داخل اپ؛ بدون وابستگی به اینترنت.
- نمایش تاریخ برای کاربر: **جلالی/شمسی**.
- ذخیره داخلی و API آینده: `DateTime` استاندارد و در Backend ترجیحاً UTC/ISO-8601. هیچ تاریخ جلالی به‌عنوان منبع حقیقت در دیتابیس ذخیره نمی‌شود.
- اعداد رابط کاربری فارسی‌اند؛ مقادیر عددی در لایه داده عدد باقی می‌مانند.

## روزهای هفته
در هیچ نمودار یا تقویم اصلی از حرف تک‌حرفی مثل «ش / ی / د» استفاده نمی‌کنیم. عناوین کامل:
شنبه، یکشنبه، دوشنبه، سه‌شنبه، چهارشنبه، پنجشنبه، جمعه.

## پیاده‌سازی
`lib/core/utils/jalali.dart` تبدیل Gregorian ↔ Jalali را بدون پکیج خارجی انجام می‌دهد.
`lib/core/widgets/jalali_date_picker.dart` Date Picker جلالی reusable است.
`formatJalaliDate` و `formatJalaliNumeric` تنها مسیر پیشنهادی نمایش تاریخ در UI هستند.

## QA ضروری
- مرز نوروز و اسفند سال کبیسه.
- ماه‌های ۳۱/۳۰ روزه.
- انتخاب تاریخ قبل/بعد از محدوده مجاز.
- جهت فلش‌های ماه قبل/بعد در RTL.
- خوانایی عنوان کامل روزهای هفته روی عرض‌های ۳۲۰ تا ۴۳۰ پیکسل.
