# نفس v1.0.0 — محدوده نهایی لانچ

این نسخه، محدوده محصول برای لانچ اولیه را تثبیت می‌کند:

- هسته برنامه Offline-first و بدون ورود اجباری است.
- داده‌های اصلی کاربر روی دستگاه ذخیره می‌شوند.
- ورود با شماره موبایل، Google Sign-In و Cloud Sync برای نسخه بعدی رزرو شده‌اند.
- دیوار امید تا آماده‌شدن Backend و Moderation در وضعیت «به‌زودی» است.
- اعلان‌های محلی، تنظیم ساعت فارسی، Health Timeline، هدف مالی، ثبت هوس، تاریخچه، تنظیمات، حریم خصوصی، قوانین و پشتیبانی در محدوده V1 هستند.
- Package ID نهایی: `ir.wearepulse.nafas`
- نسخه محصول: `1.0.0`
- Build number: `12`
- پشتیبانی: `info@wearepulse.ir`
- طراحی و توسعه: PULSE — امیرمحمد شاه‌پرستان

## موارد خارج از V1.0

- OTP و پنل پیامکی
- Google OAuth
- حساب کاربری و Cloud Backup/Sync
- دیوار امید آنلاین و Moderation
- Push Notification سروری
- قابلیت‌های درآمدی Premium/In-App Purchase

این موارد بعد از انتشار نسخه پایه و دریافت بازخورد کاربران وارد Roadmap می‌شوند.
