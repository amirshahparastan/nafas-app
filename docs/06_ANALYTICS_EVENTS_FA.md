# Analytics Event Plan

هیچ متن آزاد Community، نام مستعار یا داده حساس سلامت را به analytics provider ارسال نکن.

## Funnel
onboarding_started / onboarding_completed / goal_created / dashboard_viewed

## Craving
craving_started / craving_trigger_selected / craving_completed / craving_result

## Community
hope_wall_viewed / hope_post_composer_opened / hope_post_created / hope_reacted / hope_reported

Properties مجاز: app_version, platform, days_since_start_bucket, verified_badge_boolean. متن پست ممنوع.

## Retention
session_started / day_returned / slip_logged

هر provider قبل از لانچ از نظر privacy، opt-out و دسترس‌پذیری در ایران بررسی شود.
