# Visual Warmth & Money Input — v0.7

## تصمیم طراحی
هویت اصلی نفس همچنان سبز و آرام است. رنگ‌های ثانویه فقط در نقش‌های معنایی و سطح‌های نرم استفاده می‌شوند تا UI از حالت تک‌رنگ و سرد خارج شود.

### نقش رنگ‌ها
- Green: پیشرفت، ترک، سلامت عمومی
- Coral: اقدام فوری و craving CTA
- Gold/Sun: پول، هدف مالی، achievement
- Sky: تقویم، insight و analytics
- Lilac: community، reflection و مسیر شخصی
- Rose: safety/help

## پول و مبلغ
- مخفف تک‌حرفی «م» ممنوع است.
- واحد «تومان» باید جدا و خوانا نمایش داده شود.
- ورودی مبلغ grouping سه‌رقمی دارد.
- shortcutها با عبارت کامل «میلیون» نوشته می‌شوند.
- مقدار داخلی همچنان integer تومان ذخیره می‌شود.
