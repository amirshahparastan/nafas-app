# UX Flow Map

## ورود اول
Intro → Consumption Setup → Quit Date → Financial Goal → Home

## Navigation
Bottom Nav: **خانه / سلامت / امید / هدف / آمار**

Settings از Header باز می‌شود. Craving یک action اضطراری است نه Tab.

## هوس
Home/FAB → شدت ۱..۵ → Trigger → تمرین ۳ دقیقه‌ای → شدت بعد → نتیجه → ثبت → بازگشت

## دیوار امید
Home Preview یا Tab امید → Feed → Reaction / Report

Compose → Alias → Message → انتخاب نمایش روزهای پاکی / مبلغ ذخیره → Publish

## لغزش
Home → ثبت لغزش → تعداد + علت → تأیید → Current streak reset، Journey history حفظ

## UX Guardrails
- فرم اضطراری طولانی ممنوع
- Notification permission در ثانیه اول نصب ممنوع
- متن سرزنش‌گر ممنوع
- Social feed بدون follower count و dopamine loop
- کامنت و دایرکت در V1 ممنوع
