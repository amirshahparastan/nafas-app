# Feedback & Support

## دسته‌بندی‌ها
- پیشنهاد
- گزارش مشکل
- تجربه کاربری
- محتوا
- سایر

## فیلدها
- category
- message
- optional contact
- app version (automatic in production)
- device/platform metadata فقط با رضایت کاربر
- optional screenshot در نسخه بعد

## UX
کاربر نباید برای ارسال پیشنهاد مجبور به Login باشد.
برای Bug Report می‌توان گزینه «ارسال اطلاعات فنی» را جداگانه opt-in کرد.
