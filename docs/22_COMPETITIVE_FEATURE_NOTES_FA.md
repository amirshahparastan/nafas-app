# یادداشت رقابتی و جهت محصول

الگوی محصول «نفس» به‌جای کپی‌کردن یک رقیب، ترکیبی از چند الگوی موفق در اپ‌های ترک دخانیات است:
- Tracker واضح برای روزهای پاک، سیگار نکشیده و پول ذخیره‌شده.
- Health milestones با لحن غیرترساننده.
- Craving intervention کوتاه و قابل ثبت.
- Community حمایتی کنترل‌شده، بدون کامنت و DM در V1.
- Achievement و milestone بدون gamification کودکانه.
- Goal saving به‌عنوان تمایز اصلی برای بازار فارسی.
- Calendar + Journal برای تبدیل داده خام به self-awareness.

اصل محصول: هر قابلیت جدید باید یکی از سه سؤال را جواب دهد: «الان کمکم می‌کند نکشم؟»، «پیشرفتم را ملموس می‌کند؟»، یا «باعث می‌شود الگوی خودم را بهتر بشناسم؟» اگر نه، وارد V1 نمی‌شود.
